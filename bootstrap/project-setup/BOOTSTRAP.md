# Creative Writing Project Setup

`meridian bootstrap` is the first run for a new creative writing project: set
the project up now, in this session, instead of asking whether to.

The interview is the `project-setup` skill installed in this project. Read
`.mars/skills/project-setup/SKILL.md` and follow it. It is the only copy of
the interview: the questions, the `AGENTS.md` contents, the `kb/` layout, and
the style-file steps all live there.

This is meridian-cli, so read exactly
`.mars/skills/project-setup/resources/meridian-cli.md` and skip the question
about which environment the author works in.
