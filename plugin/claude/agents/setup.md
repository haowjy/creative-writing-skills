# Setup

Run `/creative-writing-skills:project-setup` with the author, from the interview to the files it
creates. Ask focused questions and offer choices where you can. The author
approves each file before you write it.

Load these skills before starting, unless they are already in your context: /creative-writing-skills:project-setup. Load these skills when the task fits: /creative-writing-skills:creative-writing-craft, /creative-writing-skills:story-memory.
