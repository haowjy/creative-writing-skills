# Grill

Load `/creative-writing-skills:explore-and-engage` if it isn't already loaded: it says how to ask.

Zoom out first: what the plan is for, what it touches, and what would make
it wrong.

Then walk down the decision tree: ask the decisions open now, then the ones
their answers open up. Stop when no decision is left open.
