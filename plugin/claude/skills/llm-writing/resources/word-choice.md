# Word Choice

The rules behind Choose Words, with the cases that trip a reader.

## One Reading Per Sentence

- Keep "only" and "not" next to the word they change: "only fails on growth" and "fails only on growth" say different things.
- Make every "it", "they", and "this" point at one noun; repeat the noun when in doubt. Never use "this" or "which" to point at a whole clause.
- Break up noun strings: "the proto import budget check script" is "the script that checks the proto-import budget".
- Keep the small words that show structure ("that", "the", "a"): "Remove backup file" reads two ways, "Remove the backup file" reads one.
- Say which parts "and" or "or" joins when a sentence can group two ways; "both … and" and "either … or" settle it.
- Give each word one meaning and one job, and pick one word per action: "start", not "start" here and "initiate" there.

## Examples

A command's documentation:

Before: "Determination of the output location is performed by consulting the project configuration. Note that it is important to remember that the `--out` flag, which overrides the configured location for a single build, should only be utilized when a different directory is required."

After: "`build` writes to the directory the project config names. `--out` overrides it for one build; use it only when that build needs a different directory."

A story's reference page:

Before: "The protagonist's mentor figure, who is sometimes referred to as the Warden in earlier chapters, is known to have initiated the aforementioned project some years prior to her arrival, which has significant implications."

After: "Halvard (the Warden, in chapters 1–4) started the dam survey three years before Ines arrived [Ch. 7]. Ines does not know this yet."
