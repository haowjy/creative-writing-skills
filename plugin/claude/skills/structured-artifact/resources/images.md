# Images

Label proposals and illustrations so they can't be mistaken for observed
results, and illustrative dimensions so they can't be mistaken for
measurements. Mark controls in a drawn interface that don't work.

Keep scale and alignment the same across images that are compared.

Keep annotations anchored to the image as it resizes. An SVG overlay can
share the image's coordinate system; separately positioned HTML labels need
the same scaling. Check that callouts don't cover the detail they explain.

Give each informative image alt text, and a complex one an explanation beside it.
